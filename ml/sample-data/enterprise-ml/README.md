# Fictional organization-specific directory samples

These represent two distinct enterprises. The same stable-looking group key
`S-1-5-21-1001` intentionally carries different meaning under different
`organization_key` and `directory_key` values. **Never join by display name**.

Before importing `ad_groups_export.csv` and `transfers.csv`, create the fictional
`EMP-001` employee and its linked applications in your test database.

`ad_group_catalog` must be approved by a group/resource owner. A group with
unknown meaning remains an evidence gap; do not guess privilege from a name.

`column_map_ad.json` shows a sample organization-specific column adapter, not a
universal AD export schema. Source identity, completeness and timestamps must be
provided and attested by the collection team.
